# 测试报告：NODKA unitree 板 4×ISX031 中 port C 无法工作 —— 定位为相机供电（PoC）预算不足

日期：2026-07-16
平台：NODKA "unitree" 板（PTL / IPU75XA，Intel IPU7）
相机：4× Leopard Imaging ISX031（GMSL2，MAX9295A 串行器 @I2C 0x62，4-lane）
反序列化器：MAX96724 @I2C 0x27（1 颗，4 条 GMSL 输入 Link，输出经 cphy A → IPU mipi0）

---

## 1. 现象

4 个 ISX031 分别接到 MAX96724 的 4 条 GMSL Link（port A/B/C/D = Link 0/1/2/3）。软件识别时：

- **port A / B / D（Link 0/1/3）：正常** —— 串行器和 sensor 都 probe 成功。
- **port C（Link 2）：失败** —— 两种表现（间歇）：
  - 串行器勉强起来，但 sensor 读 module-ID 失败：
    ```
    isx031: Invalid module ID: expected 0x0031, got 0x0fff
    isx031: Failed to identify sensor module: -19
    ```
  - 或串行器根本联系不上（DES 侧）：
    ```
    max96724: Failed to wait for serializer at 0x62 or 0x45: -121
    max96724: Cannot find serializer for link 2
    ```
    `-121` = EREMOTEIO，GMSL **反向控制通道**物理层错误；`0x0fff` = I2C 读全 1（设备无有效响应）。

---

## 2. 关键对照实验（结论性证据）

用**完全相同**的 ACPI 配置（只启用 Link 0=port A 与 Link 2=port C 两路），唯一变量是 **port B/D 上的相机有没有物理插着**：

| 测试 | 配置表 | port B/D 相机 | port A 结果 | port C 结果 |
| --- | --- | --- | --- | --- |
| A | A+C 两路表 | **插着** | ✅ 正常 | ❌ 串行器 `-121` 起不来 |
| B | A+C 两路表（同一份）| **拔掉** | ✅ 正常 | ✅ **正常** |

**表没变、启用的 Link 数没变、I2C 地址/别名没变 —— 仅把 B/D 两个相机拔掉，port C 立刻恢复正常。**

这说明 port C 的失败**取决于系统里同时接入的相机总数（总负载）**，而不是 port C 那一路本身的信号或配置。

---

## 3. 已排除的因素（逐一实测排除）

| 排除项 | 如何排除 |
| --- | --- |
| 相机模组坏 | port A↔C 相机对调：已知good的模组换到 C 仍失败；C 上的模组换到 A 正常。故障不跟模组走。 |
| 同轴线坏 | 换过 port C 的线，无变化。 |
| I2C 别名冲突 | port C 相机别名 0x56→0x55 改过，无变化；且失败发生在 DES↔串行器一级，比相机别名更早，别名根本没用到。 |
| ACPI pipe-stream-autoselect | 显式关闭过，无变化。 |
| GMSL 链路速率余量 | 驱动会自动 6Gbps→3Gbps 回退（max_des.c），两档都失败，非速率问题。 |
| 反向 I2C 速率 | 已降到 100kHz（NVIDIA 参考值），无变化。 |
| MIPI 端口 / DES 芯片 | mipi0（I2C0）与 mipi1（I2C1）两颗独立 MAX96724 上，port C 都失败，现象一致。 |

---

## 4. 根因结论

**相机供电（PoC / camera power rail）预算不足：板子无法同时为 4 个 ISX031 供电。**

ISX031 是 4-lane 高速 GMSL 相机，单个功耗较高（约 1~2W 量级，需硬件实测确认）。4 路同时上电时，共享供电掉压，**port C 这一路最先低于串行器/传感器的工作电压**（推测因其在供电链上余量最小 —— 走线最长/最靠末端/限流偏保守），导致：串行器供电不足 → 反向通道 `-121` 起不来；即使勉强起来，sensor 电压不够 → 读不到（`0x0fff`）。

减少同时接入的相机数量（4→2）后，供电足够，port C 即恢复正常，与上述对照实验完全吻合。

> 补充：此前"两个 D457 接 port A + port C 能工作"也符合此结论 —— 那也只是 2 个相机、且 D457 功耗/工作点不同，在供电预算内。

---

## 5. 请硬件工程师协助确认 / 提供的信息

1. **相机供电架构**：4 个相机口的供电是共享一路还是各自独立？供电方式是 PoC（Power over Coax，经同轴）还是独立供电线？
2. **总电流能力**：给相机的那路电源（含 PoC 注入）的**总输出电流上限**是多少？
3. **单口限流**：每个相机口是否有独立限流？限流值是多少？port C 的限流/串阻是否与 A/B/D 不同？
4. **实测电压**：4 路相机全接、上电瞬间和稳态下，**测量 port C 相机端的供电电压**（以及 A/B/D 做对照），看是否掉压/低于 ISX031 与 MAX9295A 的最低工作电压。
5. **ISX031 模组功耗规格**：确认单个 ISX031（含 MAX9295A 串行器）的峰值/稳态电流，×4 与板子供电能力比对。

**验证建议**：逐步增加相机数量（2→3→4），记录在第几个相机接入时 port C（或其他口）开始掉线，即可定位供电能支持的相机数量上限，并反推需要加强多少供电余量。

## 附：软件侧结论

ACPI/驱动配置本身正确 —— A/B/D 三路稳定工作已证明 4-link 模板无误。软件侧无需再改动；问题在硬件供电。
